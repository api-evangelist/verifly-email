Fast, accurate email verification API, single, batch, and async bulk verification (up to 1M) with disposable detection, role filtering, catch-all and SMTP checks, plus a native MCP server for AI agents. Pay-as-you-go, credits never expire.

**Areas:** Email Verification · API · MCP · Developer Tools · Verification · Company

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
